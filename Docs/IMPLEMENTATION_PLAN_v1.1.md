## 3. 本轮验收标准

1. 15、30、60 FPS 下，相同时间后的跟随比例和惯性衰减一致。
2. Timer 延迟不会造成一次超大物理跳跃。
3. 宠物中心不在任何屏幕内时，仍选择与宠物相交最多或距离最近的屏幕。
4. 新增数学与屏幕几何测试全部通过。
5. 网络、第三方依赖、SwiftUI 自驱动动画和多时钟红线继续保持通过。
6. arm64 与 x86_64 Debug build 通过。

## 4. 变更纪律

- 不启动未获授权的运行时验收。
- 不修改 Bundle ID、外部产品名、签名或发布渠道。
- 不引入第三方 package。
- 不增加联网、遥测或新权限。
- 不把动态宠物图集支持塞进静态图片 MVP。
- 运行时实测前不宣称交互或性能达标。
